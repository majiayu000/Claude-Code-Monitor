# Design Specifications

The directories in this tree contain design records for completed and ongoing
work. In particular, the `GH99` through `GH105` specifications are retained as
historical records of the decisions and implementation scope for those issues.

SpecRail runtime checkpoints, including `.specrail/runtime/current.json`, are
generated execution state. They are local workflow data rather than source
code and must not be committed or archived under `specs/`.
